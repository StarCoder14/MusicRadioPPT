[여는 법]
index.html 을 크롬이나 엣지로 열면 됨. 열고 나서 F 키를 누르면 전체 화면.

[조작키]
오른쪽 방향키 / 엔터 / 마우스 클릭             다음
스페이스                                       영상 재생 / 멈춤 (영상 없는 화면에서는 아무 일도 안 일어남)
왼쪽 방향키 / 백스페이스                       이전
F                                              전체 화면 켜기 끄기
B                                              BGM 켜기 끄기 (비상용. 평소엔 자동으로 켜지고 꺼짐)
P                                              스페이스랑 똑같음
T                                              연습용 타이머 보이기 숨기기 (10~12분 안이면 초록, 넘으면 빨강)
Home / End                                     맨 처음 / 맨 끝
한글 입력 상태여도 F, B, P, T 다 먹음.

[BGM]
BGM은 오프닝이랑 클로징 두 화면에서만 나옴. 키 안 눌러도 알아서 켜지고 꺼짐.
오프닝: 대기 화면에서 넘겨서 ON AIR 불이 켜지는 순간 2초 동안 커짐. 사연 영상으로 넘기는 순간 2.5초 동안 작아지면서 꺼짐.
클로징: 화면에 들어오는 순간 커짐. 마지막에 한 번 더 눌러서 ON AIR 불이 꺼지면 같이 작아지면서 꺼짐.
뒤로 가서 오프닝이나 클로징에 다시 들어와도 똑같이 켜짐.
B는 비상용. 다른 화면에서 B로 켜도 다음 화면으로 넘기면 꺼짐. 줄어드는 중에 B를 또 누르면 그 자리에서 다시 커짐.
어느 화면에서 나올지는 index.html 에서 section 에 data-bgm="on" 붙은 곳으로 정해짐.

[ON AIR]
대기 화면에서 넘기면 화면이 ON AIR 불빛으로 확대됐다가, 불이 켜지고 나서 줌이 풀리면서 방송이 시작됨.
클로징 화면에서 마지막 멘트가 끝나고 한 번 더 누르면 같은 방식으로 불이 꺼짐.
줌이 움직이는 2~3초 동안은 키를 눌러도 안 넘어감. 여러 번 눌러도 꼬이지 않게 막아 둔 것.
평소에 넘길 때는 지지직 → 잠깐 빈 화면 → 다음 내용이 또렷해지는 순서로 0.9초 정도 걸림. 이때도 키 입력은 막힘.

[화면 순서]
대기 → 오프닝 → 사연 영상 → 영등굿 소개(말) → 영등굿 영상 → 영등굿 소개(말) → ④ → ⑤ → 음악 소개 → 공익광고 → 협찬 → 클로징
오프닝, 영등굿 소개 두 개, ④, ⑤, 협찬, 클로징은 사람이 직접 말하는 부분이라 가운데를 일부러 비워 둠.

[영상, 소리 넣는 법]
아래 이름 그대로 videos 폴더에 넣으면 자동으로 들어감. 없으면 화면에 빈칸이랑 파일 이름이 보임.
영상 화면에 들어가면 첫 장면에서 멈춘 채로 기다림. 스페이스를 눌러야 재생됨.
끝나면 마지막 장면에서 멈춰 있고, 다음 키를 눌러야 넘어감. 끝난 영상에서 스페이스를 누르면 처음부터 다시 나옴.
넘어가는 연출(지지직, ON AIR 줌) 중에는 스페이스도 안 먹음.

videos/sayeon.mp4        사연 영상
videos/yeongdeunggut.mp4 영등굿 영상
videos/gongik.mp4        공익광고 영상
videos/music.mp3         음악 소개 노래 (김광석 - 바람이 불어오는 곳, 0:55까지 자르고 앞뒤 페이드 넣음)
                         음악 화면도 영상처럼 들어가면 기다리고, 스페이스로 재생 / 멈춤.
                         저작권 때문에 깃허브에는 안 올림. 다른 컴퓨터에서 받으면 이 파일만 따로 넣어야 함.
videos/bgm.mp3           BGM (Suno로 만든 Broadcast from 2126). mp3 말고 bgm.m4a, bgm.mp4 도 됨

videos/sfx-onair-off.wav ON AIR 꺼질 때 효과음. 딸깍딸깍 하고 웅 소리가 낮아지며 사라짐
videos/sfx-glitch.wav    화면 넘길 때 지지직 효과음 (0.35초)

[효과음 고치는 법]
효과음 세 개는 make_sounds.py 로 직접 만든 소리임. 파일 안 숫자를 바꾸고  python make_sounds.py  돌리면 새로 만들어짐.
소리 크기는 맨 위 ON_AIR_LOUDNESS, GLITCH_LOUDNESS 를 바꾸면 됨 (1.0이 최대).
띵 소리 높이는 ding( ) 안 첫 숫자(Hz), 웅 소리 높이는 sliding_tone( ) 안 숫자.

[주의]
글꼴은 인터넷에서 받아 옴. 발표하는 컴퓨터에 인터넷이 안 되면 맑은 고딕으로 바뀌어서 나옴.
발표 전에 그 컴퓨터에서 한 번 미리 열어 볼 것.
